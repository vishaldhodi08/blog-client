# Blog Client

React frontend for a full-stack blog platform, connecting to a self-built Express/MongoDB REST API.

🔗 **Live Site:** https://stellar-starlight-3ad7d9.netlify.app/
🔗 **Backend API:** https://blog-api-m29k.onrender.com/

## Features

- View all blog posts, sorted newest first
- Read full post details
- Create new posts
- Delete posts with confirmation
- Fully connected to a self-built backend (not a third-party API)

## Tech Stack

- React (via Vite)
- React Router
- Axios
- Tailwind CSS

## How to Run Locally

1. Clone the repository

```bash
   git clone https://github.com/vishaldhodi08/blog-client.git
   cd blog-client
   npm install
   npm run dev
```
